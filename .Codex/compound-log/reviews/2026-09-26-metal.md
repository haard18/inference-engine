# 2026-09-26 - Metal review

## Delivered

- A Mac GPU matrix kernel for f32, f16, bf16, Q8_0, Q5_0, and Q4_K.
- A reusable Metal runtime that owns uploaded weights and creates generation sessions.
- Grouped GPU commands for projections that share an input vector.
- A GGUF text probe with a `--metal` option.

## Validation

- Tiny f32 and f16 CPU/Metal score comparisons.
- Full real-model bf16, Q8_0, and Q4_K_M CPU/Metal score comparisons below `1e-3` maximum difference.
- Two concurrent sessions sharing a prepared runtime.
- Eight-token text generation on CPU and Metal.
- Full release test suite, formatting, and lint checks.

## Scope

Metal currently accelerates matrix operations only. CPU calculations remain between GPU commands, and GPU weights duplicate the model's CPU weight storage. The local run was slower and used more memory than CPU execution. Serving, bounded GPU scheduling, and GPU-resident transformer state remain open.
