# 2026-09-26 - GGUF Q8_0 review

## Delivered

- A GGUF v3 metadata and tensor reader for the supported Llama-style layout.
- Q8_0 block storage and CPU matrix multiplication without expanding the model to f32 weights.
- Interleaved rotary positions for GGUF query and key tensors.
- A GGUF text probe using the project-owned tokenizer with the matching JSON file.

## Validation

- Exact Q8_0 block operation on a small matrix.
- Rejection of overlapping and truncated tensor ranges.
- Real GGUF next-token scores against an independent NumPy Q8_0 reference, with `1e-3` tolerance.
- Text prompt smoke check, full release test suite, formatting, and lint checks.
- Peak memory comparison for the same prompt on GGUF and Safetensors.

## Scope

The current GGUF reader accepts F32, F16, BF16, and Q8_0 tensor descriptors for the supported Llama-style model. It rejects other quantized formats and rotary scaling. The text probe still uses a matching tokenizer JSON file; loading the tokenizer from GGUF metadata remains a required layer.
